# Sales Analysis

A beginner data-analysis project using **sample (practice) sales data** of a small store from January to March. It is not real sales data.

## Features
- Total sales per product and per month
- Best-selling product and average sales
- 5 SQL queries (SUM, GROUP BY, ORDER BY, AVG)
- A web page with a bar chart
- A CSV file that can be opened in Excel to make a chart

## Tech
Excel (CSV), MySQL, HTML, CSS, JavaScript

## Files
- `sales.csv`: the data (open in Excel)
- `queries.sql`: creates the table, inserts the data, and has the queries
- `index.html`, `style.css`, `script.js`: the page with the summary and the chart
